# Student Performance Analysis Dashboard

An interactive Excel dashboard for analyzing the academic performance of 30 students.

##  Tools & Features

- Microsoft Excel
- Slicers
- SORTBY
- INDEX & MATCH
- Conditional Formatting
- Sparklines
- In-cell Charts
- Custom Number Formatting
- Line Charts

##  Project Highlights

- Student ID sorting and gender lookup
- Grade and performance visualization
- Study time and absenteeism analysis
- Travel time analysis
- Family size and health visualization
- Interactive data presentation using charts and formatting
