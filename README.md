# student-analysis-dashboard
Student Performance Analytics Dashboard
An interactive one-page Excel dashboard to explore the performance of 30 students. Pick a column and a sort order with slicers, and the whole dashboard re-sorts instantly.
Tools & Features
-> Microsoft Excel
-> Slicers
-> SORTBY
-> INDEX & MATCH
-> Conditional Formatting
-> Sparklines
-> In-cell ChartsCustom Number Formatting
-> Line Charts
Project Highlights
-> Student ID sorting and gender lookup
-> Grade and failure visualization
-> Study time, absenteeism, and travel time analysis
-> Family size and health visualization
-> Interactive data presentation using charts and formatting
